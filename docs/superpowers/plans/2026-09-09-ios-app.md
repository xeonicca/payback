# Payback iOS Implementation Plan

**Goal:** Convert Payback to an iOS app while retaining the web product.
**Architecture:** Shared Vue frontend; bundled Capacitor SPA calls the existing
Nitro backend using Firebase ID tokens. Web retains session cookies.
**Tech stack:** Nuxt 4, Vue 3, Firebase, Capacitor 8, Swift Package Manager.
**Spec:** ../specs/2026-09-09-ios-app-design.md

## Constraints and decisions

- Preserve all pre-existing uncommitted changes; work on codex/ios-app in place
  because the in-progress native files are part of the requested starting point.
- Do not deploy or publish. No account credentials enter version control.
- API origin and site origin are explicit public configuration, not guessed.
- Keep a single JavaScript Firebase identity on native and web.
- Task state lives here because this project has no existing Codex memory dir.

## Tasks

- [x] API transport: create useApi using runtime API origin on native; migrate
  invitation, join, member edit, leave and guest-upgrade calls. Verify existing
  same-origin web behavior and rejection of unsafe native origins with Vitest.
- [x] Server authentication: extend session middleware for verified ID tokens,
  retain cookie fallback only when no bearer header exists; add restricted CORS.
  Test native, web, absent, expired/invalid credentials and preflight requests.
- [x] Native identity: use skipNativeAuth, signInWithGoogle + linkWithCredential
  for guest upgrades, and preserve UID. Test bridging and error behavior.
- [x] Navigation and receipts: handle cold/warm app links, login return path,
  public share origins, camera/library selection; preserve browser file input.
  Verify link allowlist and cold/warm route handling.
- [x] Native project: sync SPM authentication plugin, register Firebase plist,
  photo permissions, URL scheme and iOS deployment target. Document Firebase,
  API configuration, universal links, signing and TestFlight prerequisites.
- [ ] Verification: tests, targeted lint, web build, static native build,
  Capacitor sync, simulator compilation and visual smoke check.
